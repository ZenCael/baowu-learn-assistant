# 宝武学习助手（BaoWuLearn）

针对宝武学习平台（learn.baowugroup.com）的**纯 API 模式**自动学习助手。
不加载、不显示平台任何页面——与平台之间只有 HTTP 接口通讯。
支持 Windows / macOS 双平台。

> ⚠️ **免责声明**：本项目为个人学习自动化工具，仅供技术交流。自动化行为可能违反
> 平台服务条款，账号风险由使用者自行承担；请在了解相关规定的的前提下谨慎使用。

## 自动更新

从 v1.0.41 起内置更新通道：启动后与每 24 小时各静默检查一次，发现新版本时
窗口顶部亮横幅，点击才会下载与替换（挂机进行中绝不覆盖自己）。

- **信任模型**：更新清单（`update.json`）带 ed25519 detached 签名（`update.sig`），
  公钥内嵌客户端、私钥仅在发布机。任何镜像节点被污染都伪造不了新版本或产物内容；
  清单的 `pubDate` 单调前进，签名的旧清单原样重放也会被拒（防降级）。
- **国内可达**：GitHub 直连（跟随系统代理）在前，公共反代前缀列表兜底，
  列表在设置页可自行增删，清单也会下发推荐列表。
- **安装**：Windows 等进程退出后原位替换（旧版留 `.bak` 自动回滚；v1.0.43 起
  换装指令以 UTF-16 `-EncodedCommand` 直传 PowerShell，中文用户名路径不再被
  代码页毁掉——v1.0.41 的 bat 方案在中文 %TEMP% 下会静默失败）；
  macOS 原子交换 `.app`（同卷 rename，不存在半新半旧状态）。
- **失败可见**：换装未成功会在下次启动写进日志页与设置页状态条（旧版已自动回滚，
  可直接重试）。
- **诊断**：`宝武学习助手 --updatecheck`（可加 `--download` 顺带验证产物 sha256）
  打印端点链与每一环结论，不发版就能验证更新路是否通。

## 多人挂机（v1.0.42）

一个窗口可以同时登录并挂机多个账号：登录后用侧栏「挂后台·切换账号」把当前
账号连引擎留在池里继续挂，回登录页再登下一个（验证码人工逐个过）。

- **隔离模型**：每个账号一套独立 ApiClient/token/引擎/会话保活/零点预警，
  账号之间零共享；平台对每个账号只发一个会话，互不干扰
- **多挂机总览页**：一屏看全所有账号的状态（挂机中/已暂停/已过期/空闲）、
  当前课程进度与队列完成度，行级「打开 / 开始 / 停止 / 重新登录 / 移除」
- **全部开始错峰启动**：批量拉起会排随机间隔（首个约 10 秒，其后逐个 1~4 分钟）——
  N 台引擎同秒起跳是多人挂机唯一的强机器特征，刻意不做同秒批量
- **过期独立处置**：某账号跨零点掉线只红它自己那一行，重登后自动续挂，其他账号不受影响

## 形态说明

本项目为**纯 API 桌面客户端**：逆向平台前端 JS 得到全部业务接口后，
脱离浏览器直接与网关通讯。心跳拟人化、学时账本对齐、结算轮询确认，
以及 46 项离线启动自检（`--selftest`）。

## 技术要点

- **协议逆向**：从前端 bundle 反推私有 API（SM2 加密登录、两本账学时模型、ES 全文检索）
- **国密对齐**：C# BouncyCastle 输出与网页端 `sm-crypto` 完全同构的 SM2 密文
- **两本账模型**：课件播放位置 ≠ 平台计入学时（每跳心跳最多计 60s），引擎按平台口径记账
- **拟人化**：心跳间隔 58–63s 随机、请求指纹对齐真实浏览器
- **自检**：`宝武学习助手 --selftest` 离线跑 46 项断言（含逐页面真实例化，编译通过≠界面能开）
